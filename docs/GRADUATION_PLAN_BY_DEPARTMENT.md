# مذكرة تشغيل: خطة التخرج حسب القسم

## للمستخدمين (رؤساء الأقسام / الإدارة)

- في شاشة **إدخال بيانات الطلبة**، حقل «خطة التخرج» يعرض **هدف وحدات قسمك** تلقائياً (مثال: المدني 161، الميكانيكا 155).
- قائمة **150 / 155** تظهر فقط لقسم **الهندسة الميكانيكية** كنظام وحدات تراثي (طلاب قدماء)، وليست خطة منهج لباقي الأقسام.
- عند إضافة طالب كرئيس قسم، يُربط تلقائياً بقسمك؛ لا حاجة لاختيار «خطة الميكانيكا».
- سياسات التخرج من صفحة رئيس القسم: غير الميكانيكا تستخدم «هدف تخرج القسم»؛ الميكانيكا تبقي 150/155 إن لزم.

## للمطوّرين

- مصدر الحقيقة: `backend/core/graduation_targets.py` + `DEPT_GRADUATION_TARGETS`.
- API: `GET /students/graduation_plan/options?student_id=&department_id=`.
- مزامنة `programs.min_total_units` لـ `PROG_MAJOR` عند ترحيل SQLite/Postgres.
