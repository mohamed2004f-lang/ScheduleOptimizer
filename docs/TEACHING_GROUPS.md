# مجموعات التدريس — دليل تشغيل

## المفاهيم

| المصطلح | المعنى |
|---------|--------|
| **حصة جدول** | صف في `schedule` (يوم + وقت) |
| **مجموعة تدريس** | طلاب + أستاذ + مقرر + قسم + فصل (A/B أو «الكل») |
| **single** | محاضرات متعددة لنفس الطلاب |
| **split** | مجموعات A/B منفصلة — يُختار عند التسجيل |

## فريق التدريس (رئيسي + مساعد)

- الجدول `teaching_group_instructors`: `(teaching_group_id, instructor_id, role)` حيث `role ∈ {primary, assistant, co_teacher}`.
- `teaching_groups.instructor_id` = الأستاذ **الرئيسي** (للتوافق مع مقرراتي/التقييم).
- العرض في الخلية: `رئيسي + مساعد: …`.
- «مقرراتي» تظهر للمجموعة لكل من الرئيسي والمساعد.
- تعارضات الأساتذة تشمل المساعدين عبر ربط المجموعة.

API:
- `GET /schedule/teaching_groups/<id>/instructors`
- `PUT /schedule/teaching_groups/<id>/instructors` — `{ primary_instructor_id, assistant_ids: [] }`

من صفحة إعداد المجموعات: اختر الرئيسي وقائمة المساعدين ثم احفظ.

## متى تستخدم single vs split

- **single**: المقرر له عدة محاضرات في الأسبوع و**نفس الطلاب** يحضرون كلها (ميكانيكا: أحد + أربعاء).
- **split**: الطلاب **مقسّمون** على مجموعات حضور (A صباحاً، B مساءً).

## خطوات الإعداد (فصل جديد)

1. افتح **إعداد مجموعات التدريس** من صفحة الجدول (`/schedule_teaching_groups`).
2. راقب بطاقة **صحة الفصل** (سليم / يحتاج متابعة / حرج).
3. **الأسرع:** اضغط **ترحيل الفصل كاملاً** (حصص + فريق رئيسي + تسجيلات + تقييمات) ثم راجع الملخص.
4. أو نفّذ يدوياً بالترتيب: ترحيل حصص → إعداد split إن لزم → ترحيل تسجيلات → ترحيل تقييمات.
5. راجع الملخص: حصص بلا مجموعة، تسجيلات بلا مجموعة، مقررات تحتاج إعداد.

على PostgreSQL لأول مرة بعد التحديث:

```bash
alembic upgrade head
```

سطر الأوامر:

```bash
python scripts/backfill_teaching_groups.py
python scripts/backfill_teaching_groups.py --semester "خريف 44-45" --audit-only
```

### عند إضافة حصة من محرر الجدول

إن وُجد قسم + أستاذ على الصف، يُنشأ/يُربط تلقائياً مجموعة `single` افتراضية (`teaching_group_id`).
الحصص بلا قسم أو أستاذ تبقى يتيمة وتظهر في التدقيق.

## التقييم والاستبيانات

- الطالب يُقيّم **مرة واحدة لكل مجموعة تدريس** (وليس لكل محاضرة).
- عدد المسجّلين في التقارير = `COUNT` من `registrations.teaching_group_id`.
- تقرير «مجموعات بلا تقييم» يعتمد على `teaching_groups` وليس صفوف الجدول.

## الأستاذ والدرجات

- **مقرراتي** تعرض مجموعات تدريس (قسم + A/B + محاضرات).
- قائمة الدرجات تُحمّل الطلاب من مجموعة التدريس عند توفر `teaching_group_id`.
- واجهة **مسودات الدرجات** تعرض «مجموعة تدريس» (وليس «شعبة») وتمرّر `teaching_group_id` في الروستر وإنشاء المسودة.

## استكشاف الأخطاء

| المشكلة | الحل |
|---------|------|
| عدد طلاب خاطئ في التقرير | تأكد من ربط التسجيلات بمجموعة A/B |
| مقرر يظهر مرتين للأستاذ | راجع إعداد split — كل مجموعة بطاقة منفصلة |
| تقييم مكرر | تأكد من `teaching_group_id` في `course_evaluations` |
| حصص بلا مجموعة | شغّل ترحيل حصص أو اربط يدوياً من الإعداد |

## ملاحظة: `program_course_sections` (مُلغى)

شعب الكتalog القديمة (`program_course_sections`) **أُزيلت** — استخدم **مجموعات التدريس** فقط.
الخطة الأكاديمية (`program_courses`) تبقى للمتطلبات والكتalog؛ التشغيل الفعلي = `teaching_groups`.
