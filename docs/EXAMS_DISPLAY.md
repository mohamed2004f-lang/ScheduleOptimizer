# جداول الامتحانات — عقد التشغيل

## السياسة الافتراضية (الإطلاق الحالي)

| البند | القيمة |
|---|---|
| وحدة الجدولة | **امتحان موحّد على مستوى المقرر** (`course_name`) |
| لكل مجموعة تدريس؟ | اختياري عبر `exams.teaching_group_id` (فارغ = امتحان موحّد للمقرر) |
| التعارض الطلابي | نفس **التاريخ + الفترة الزمنية** لأكثر من امتحان يطابق تسجيل الطالب (مع احترام المجموعة إن وُجدت) |
| المصدر | حساب حي من `registrations` × `exams` عبر `GET /exams/<type>/conflicts?live=1` (افتراضي) |

## العرض

- مصفوفة **تاريخ × فترة** في `exams_schedule.html` (جزئي / نهائي)
- عند الإضافة: قائمة **مجموعة التدريس** (اختياري) للمقررات ذات split
- شارات تعارض على البطاقة
- نشر عبر `exam_schedule_versions` (مسودة → نشر)
- **دور الأستاذ / المشرف:** `GET /exams/<type>/rows` يعرض فقط مقررات **الفصل الحالي** المسندة له (مجموعات تدريس أو صفوف الجدول) — لا تُعرض بقايا امتحانات فصول سابقة ولا كل مقررات الكلية
- **واجهة الأستاذ:** صفحات الجزئي/النهائي **عرض فقط** (بدون إضافة/تعديل/اعتماد/تفريغ) — يبقى التصفية والطباعة والتصدير
- **التقويم الأكاديمي للأستاذ:** قراءة فقط (بدون حفظ أو إضافة عناوين)
- **رئيس القسم (وضع الرئيس):** نطاق مقررات القسم كما في التغطية؛ محرر الجدول الدراسي يبقى في قائمته وليس في قائمة الأستاذ

## ما يبقى خارج هذه المرحلة

- تغيير خوارزمية محسّن الجدول الدراسي
- أعمدة حسب الشعبة (track)
